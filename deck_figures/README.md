# Deck figures

Curated figures for weekly updates and MIC. Committed deliberately, unlike
everything under `optimization/results/`, which is gitignored because it holds
gigabytes of PPDFs.

This directory exists because there is no SSH path from the Mac to CCR: the only
route is Open OnDemand in a browser. Git is already synced in both directions
every day, so it is the transport that needs no new setup.

Keep this small. A handful of current PNGs, overwritten each week, not an
archive. Anything large or one-off should be downloaded through the Open
OnDemand file browser instead.

Refresh on CCR with `collect_deck_figures.sh`, then commit and pull on the Mac.
